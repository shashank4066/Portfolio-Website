# Portfolio Website

Personal portfolio for **Shashank** — Java Backend Developer (Spring Boot · Microservices · Azure).

Live at **https://shashankdev.tech**

## Structure

```
index.html                  # single-page site
assets/
  css/style.css             # theme, layout, animations
  js/main.js                # particle globe, reveals, counters, interactions
  img/                      # portraits + favicon
  Shashank-Resume.pdf       # downloadable résumé
CNAME                       # shashankdev.tech (GitHub Pages custom domain)
```

## Tech

Plain HTML + CSS + JavaScript. No build step, no dependencies. Hosted on GitHub Pages.

## Deploy

Push to `main` — GitHub Pages serves it at [shashankdev.tech](https://shashankdev.tech) automatically.
